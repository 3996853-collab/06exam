# 省内外流向货量对比看板设计

**目标**

基于附件 `c:\Users\ZTOCC\Downloads\query_result_2026-03-09T11_19_30.144777113+08_00.xlsx` 的流向数据，设计一个面向经营分析的数据看板，重点回答两类问题：

1. 在同省与不同省两种流向类型下，甲乙两家货量的差异有多大。
2. 在不同省流向中，甲乙两家的差异主要集中在哪些流向、哪些重量阶梯。

**数据口径**

- 主指标：`结算重量(吨)`
- 辅助指标：`票数`
- 同省：`发货省份 = 收件省名称`
- 不同省：`发货省份 != 收件省名称`
- 差值：`甲 - 乙`
- 差异率：`(甲 - 乙) / 乙`
- 重量阶梯：`0-300kg`、`300-600kg`、`600-1200kg`、`1200+kg`

**数据字段确认**

附件当前包含以下关键字段：

- `发货省份`
- `收件省名称`
- `统计日期/下单日期`
- `数据提供`
- `结算重量(吨)`
- `票数`
- `件数`
- `票均重量(吨)`
- `覆盖区县数`
- 四档重量阶梯的重量、票数、重量占比、票数占比

这些字段足以支撑看板所需的筛选、聚合和钻取分析。

**页面结构**

页面从上到下分为五个分析层级：

1. 筛选区
2. 总览卡片区
3. 同省/不同省对比区
4. 不同省流向差异区
5. 重量阶梯差异区
6. 明细表区

**模块设计**

`DashboardFilterBar`

- 提供日期、省份、流向类型、指标切换。
- 不承担数据聚合职责，只维护筛选状态。

`OverviewMetricCards`

- 展示甲总货量、乙总货量、总差值、同省差值、不同省差值、不同省占比。
- 支持点击同省/不同省卡片联动下方图表。

`FlowTypeCompareChart`

- 用分组柱状图展示同省和不同省下的甲乙货量。
- 用结构占比图展示甲乙内部的同省/不同省构成。

`InterProvinceDiffChart`

- 仅展示不同省流向。
- 对 `发货省份 -> 收件省名称` 按差值绝对值排名。
- 支持点击单个流向进行下钻。

`WeightBandCompareChart`

- 在同省和不同省两个面板下，对比四个重量阶梯的甲乙货量。
- 用热力表或矩阵展示差异集中在哪一档。

`FlowDetailTable`

- 展示筛选后的明细汇总表。
- 用于核对数据与导出前确认。

**交互规则**

- 页面默认主指标为 `结算重量(吨)`。
- 用户可切换到 `票数`，但不改变图表结构。
- 点击总览卡中的同省/不同省后，下方图表同步过滤。
- 点击不同省流向图中的某条流向后，重量阶梯区和明细表仅展示该流向。
- 提供重置下钻操作，回到全量视角。

**视觉方向**

- 延续现有项目浅色业务系统风格。
- 背景使用 `rgb(240, 242, 245)`，卡片白底，强调色使用主题青色。
- `甲` 与 `乙` 使用固定对比色，全页面统一。
- 差值使用双向色，正值和负值区分清楚。
- 重量阶梯区域视觉层级高于普通明细，突出其分析价值。

**实现约束**

- 项目为纯前端，无后端依赖。
- 附件数据需前端内置为静态样本数据，或在构建前转换为 JSON/TS 模块。
- 需要新增路由和侧边栏菜单，遵守仓库的菜单接入流程。
- 图表库需补充引入，当前项目依赖中尚无图表方案。

**风险与注意事项**

- 乙为 0 时不能直接计算差异率，需要显示为空或特殊标识。
- 不同日期同一流向可能存在多行，图表前必须先做聚合。
- 需要校验四档重量阶梯加总是否与总重量基本一致。
- 省份空值或异常值需要归类到 `未知`，避免图表断裂。
