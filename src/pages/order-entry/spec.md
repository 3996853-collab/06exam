# 物流运单录单页面需求规格

## 🎯 功能目标

创建一个功能完整的物流运单录入界面，支持：
- 日常快速录单
- 语音录入
- 智能表单（自动填充、表单验证）
- 草稿管理（暂存、加载）
- 打印导出

## 📁 项目结构

```
src/pages/order-entry/
├── index.vue              # 主页面入口
├── spec.md                # 需求规格文档
├── components/
│   ├── SenderForm.vue     # 寄件人信息表单
│   ├── ReceiverForm.vue   # 收件人信息表单
│   ├── CargoForm.vue      # 货物信息表单
│   ├── FeeForm.vue        # 费用信息表单
│   └── OrderPrint.vue     # 打印组件
└── utils/
    └── draftManager.js    # 草稿管理工具
```

## 🎨 页面布局

### 顶部区域
- 页面标题：物流运单录入
- 操作按钮：保存草稿、加载草稿、提交运单

### 表单区域
1. **寄件人信息** - 姓名、手机号、省市区、详细地址
2. **收件人信息** - 姓名、手机号、省市区、详细地址
3. **货物信息** - 名称、类型、包装、重量、体积、件数、说明
4. **费用信息** - 运费、保价费、其他费用、总费用、付款方式

### 底部区域
- 操作按钮：重置、打印、提交

## ✨ 核心功能

### 1. 智能表单
- 表单验证（必填、格式校验）
- 历史记录自动填充
- 智能提示

### 2. 语音录入
- 支持语音输入寄件人/收件人信息
- 自动解析语音内容填充表单

### 3. 草稿管理
- 本地存储草稿
- 草稿列表展示
- 快速加载/删除草稿

### 4. 打印功能
- 生成标准运单格式
- 支持打印预览
- 优化打印样式

## 🔧 技术栈

- Vue 3 (Composition API)
- Element Plus
- @element-plus/icons-vue
- print-js (打印)
- Web Speech API (语音识别)

## 📋 开发规范

参考：`/rules/development-standards.md`

### 文件要求
- 每个组件必须有 `index.vue` 作为入口
- 必须包含 `spec.md` 文档
- 复杂组件按功能拆分

### 代码规范
- 使用 Composition API (`<script setup>`)
- 组件使用 `forwardRef` 暴露方法和属性
- 遵循 Vue 3 最佳实践
